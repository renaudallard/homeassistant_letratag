# Bundled fonts

These fonts ship with the integration so the named fonts work on any Home
Assistant host without extra packages. All are redistributable under open
licenses. The files are unmodified copies of the upstream releases.

| `NotoSerif-Bold.ttf` | Noto Serif Bold | Copyright 2022 The Noto Project Authors | SIL Open Font License 1.1 ([OFL.txt](OFL.txt)) |
| `Courgette-Bold.ttf` | Courgette Bold | Copyright 2012 Sorkin Type Co, Reserved Font Name "Courgette" | SIL Open Font License 1.1 ([OFL.txt](OFL.txt)) |
| `Sancreek-Bold.ttf` | Sancreek Bold | Copyright 2011 Vernon Adams, Reserved Font Name "Sancreek" | SIL Open Font License 1.1 ([OFL.txt](OFL.txt)) |

The Bold weights are bundled because they print with the most contrast at the
printer's 26px native resolution, matching the existing built-in fonts.
