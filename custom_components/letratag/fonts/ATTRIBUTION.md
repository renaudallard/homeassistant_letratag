# Bundled fonts

These fonts ship with the integration so the named fonts work on any Home
Assistant host without extra packages. All are redistributable under open
licenses (SIL Open Font License 1.1 or Apache License 2.0).

Fonts that upstream distributes as variable fonts were instanced to their
Bold named instance (`wght=700`) with `fonttools`; they are otherwise
unmodified. Selecting an existing named instance keeps the original family
name under the OFL. The Bold weight is bundled because it prints with the
most contrast at the printer's 32px native resolution.
